# Homework

This folder is an independent workspace for course homework and assignment
submissions. Keep homework-specific notebooks, scripts, datasets, and notes
here without modifying the development implementation.

## Environment

Create the homework environment from this directory:

```bash
cd 01-rag-foundations/homework
uv sync
```

Use the homework environment when running assignment work. The development
notebooks and modules remain in `../development` and use the repository's main
development environment.
